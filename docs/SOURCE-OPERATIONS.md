## 준비 대상 API (기존 환경변수 재사용)

- 국가자격 시험일정: `HRDK_SCHEDULE_SERVICE_API_KEY` https://openapi.hrdkorea.or.kr/main
- 공공데이터포털 서비스별 승인: `DATA_GO_KR_API_KEY` https://www.data.go.kr/
- KOSIS 공유서비스: `KOSIS_API_KEY` https://kosis.kr/openapi/
- 민간자격 원장: `KRIVET_API_KEY` 보유 여부와 해당 서비스 계약 확인. 공식 CSV는 API 키 불필요.
- 나이스: `NEIS_API_KEY` https://open.neis.go.kr/
- 뉴스 검색: 보유 중인 네이버 검색 Client ID/Secret의 실제 환경변수명을 확인해 연결

이름 확인과 실제 사용 권한·호출 성공은 구별합니다. 현재 **EXAM Worker의 Cloudflare Secret은 0개**입니다.

## 16개 활용신청 후보와 데이터 파이프라인

사용자가 사전에 정리한 16개 API 중 상당수는 **별도 인증키 16개가 아니라 공공데이터포털 서비스별 활용신청**입니다. 인가된 데이터를 검증해 각 스냅샷으로 가공합니다.

1. 한국산업인력공단 시험일정: 종목·회차·접수·시험·발표일을 공식 종목 상세 페이지와 교차검증
2. 국가기술자격 종목·계열·관심종목: 검색 종목 연결
3. 시험장·지역별 취득·복수취득: 시험장 안내·정량 통계
4. 과정평가형·일학습병행: 과정/평가별 시험 정보
5. NCS 직무/분류: 직무역량 연계
6. 국가·지방 공무원: 사이버국가고시센터 및 지자체 공식 공고
7. 수능·모의평가·검정고시·교원임용: 평가원/교육청 공식 공고
8. KOSIS: 시험·자격 관련 **실제로 존재하는** 통계표만 확인 후 랭킹 산식 작성
9. 뉴스: 공식 공고 우선, 포털 뉴스검색으로 기사 존재·발행일·원문 링크 확인

## 저장·배포 규칙

- API 호출은 방문자 접속 시 하지 않습니다. 데이터 수집기에서만 공식기관으로 요청합니다.
- 모든 날짜는 ISO `YYYY-MM-DD`, 종류 `exam|apply|announce`, `verifiedAt`, 공식 `source`와 `url` 필수.
- 시험 종목 및 회차가 일치하지 않는 공통 일정은 공개 캘린더로 승격하지 않습니다.
- 공식 통계는 **기준년도, 수치, 단위, 모집단, 집계기간, 원문**이 확인되기 전까지 순위에서 제외합니다.
- 원장 갱신 전 `npm run check`에 실패하면 이전 배포 유지. 승인·호출 실패 시 임의 데이터로 대체하지 않습니다.
- 방문자는 정적 CDN JSON만 조회; D1/KV/R2/자동 Cron 모두 필요 없음.
- Cloudflare GitHub Builds 연결은 추가 승인 필요. 그 전에는 검증 후 `npx wrangler deploy`로 수동 배포합니다.
